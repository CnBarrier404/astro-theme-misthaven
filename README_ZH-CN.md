# Misthaven

> A calm place for stories and ideas.

[English](README.md) · **简体中文**

Misthaven 是一个简洁、安静的 [Astro](https://astro.build) 博客主题。它写给想在网上拥有一个安静角落的人：分享想法、故事与日常生活，让文字成为主角，其余的一切都退到后面。

[在线预览](https://misthaven.cnbarrier.com)

## 设计

**克制的色彩。** 温暖的米白底色、柔和的灰色文字，加上一抹雾蓝绿作为唯一的强调色。颜色用来告诉读者“我在哪里”“可以做什么”，而不是单纯的装饰。深色模式在夜里延续同样的气质。

**舒展的留白。** 充足的留白和稳定的间距节奏把内容一段段分开，让页面开阔而不空洞。

**以阅读为先。** 正文放在舒适的阅读宽度里，旁边是文章目录；文章标出预计阅读时长，长期未更新时会温和地提醒读者。提示框、图片说明和代码块都为正文服务，而不是与它争抢注意力。

**安静的动效。** 页面和主题之间平滑过渡，菜单轻轻展开。每一处动效都有它的理由；对偏好减少动效的读者，它们会自动让路。

**适配每一块屏幕。** 每个布局都从手机开始设计。桌面端有的导航、搜索和文章目录，手机上也都有对应的版本。

**照顾每一位读者。** 清晰的键盘焦点、便于点按的控件尺寸，以及在明暗两种主题下都易读的对比度。

## 包含什么

- **首页**：主视觉图、站点统计、分类、热门标签和最新文章
- **文章、标签与归档**：按时间、按主题或按年份浏览
- **搜索**：在导航栏直接按标题、标签、分类或描述查找文章
- **关于与友链**：带联系方式的个人卡片，以及推荐朋友站点的页面
- **浅色、深色或跟随系统**：由读者选择，站点会记住
- **便于分享与订阅**：RSS、站点地图，以及可选的文章分享图
- **评论**：可选，基于 [Artalk](https://artalk.js.org)
- **双语界面**：支持简体中文与英文

## 开始使用

需要 [Node.js](https://nodejs.org) `^22.23.4`、`^24.22.1` 或 `>=26.12.1`。

```bash
git clone https://github.com/CnBarrier404/astro-theme-misthaven.git
cd astro-theme-misthaven
npm install
npm run dev
```

然后访问 `http://localhost:4321`。保存修改后，浏览器中的页面会随之更新。

## 打造你的站点

所有设置都集中在 `src/config/` 中。可以从 `siteConfig.ts` 开始：填上你的名字和站点描述，并把 `siteUrl` 设为最终发布的地址。

## 写作

文章位于 `src/content/posts/`。复制 `_template.md`，在开头填好标题和日期，正文用 Markdown 书写即可。将 `draft` 设为 `true` 可以先把文章留给自己：本地仍能预览，但它不会被发布。

## 发布

```bash
npm run build
```

把 `dist/` 文件夹上传到任意静态托管服务；也可以推送到 GitHub，由仓库自带的工作流发布到 GitHub Pages。

上线之前，请用你自己的文章替换示例文章，并根据站点实际情况重写 `src/content/pages/privacy.md` 中的隐私政策。
