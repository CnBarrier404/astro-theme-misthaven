> 这是一篇随主题提供的示例文章。创建自己的内容后，可以安全地删除它。

Misthaven 是一个简洁、安静的 Astro 博客主题，适合记录想法、日常生活与长期积累的知识。它将阅读体验放在首位，用舒展的留白和克制的色彩承载内容。你可以把它当作一间有窗的书房：不急着把所有东西摆出来，但总能找到一处适合继续写下去的位置。

## 从这里开始

你可以复制 `src/content/posts/_template.md`，填写文章信息，然后用 Markdown 开始写作。文章会自动出现在首页、文章列表和搜索结果中，也会进入 RSS 与站点地图。

一篇文章通常由三部分组成：

1. **Frontmatter**：标题、摘要、日期、分类和标签等元数据。
2. **正文**：使用 Markdown 编写的标题、段落、列表、图片和代码。
3. **链接关系**：文章之间可以互相链接，读者也能通过分类和标签继续探索。

例如，想先了解站点配置，可以阅读[定制你的站点](/posts/customize-your-site)；想查看更完整的 Markdown 写法，可以阅读[使用 Markdown 写作](/posts/writing-with-markdown)。

### 一份简单的写作清单

- 用清晰的标题告诉读者文章主题。
- 在摘要中概括文章能带来的价值。
- 使用小标题组织较长的内容。
- 发布前检查链接、图片和代码示例。

如果文章比较长，还可以在动笔前先写一个小提纲：

- 这篇文章想回答什么问题？
  - 读者读完后应该知道什么？
  - 哪些内容可以留到下一篇？
- 哪些地方需要例子或代码？
- 哪个结论值得在开头先说清楚？

## 让内容保持可读

主题不会替作者决定文章应该写多长，但会尽量让不同长度的内容都舒适地呈现。短短几段的生活记录可以自然地结束，带有多个章节的技术文章也可以通过目录导航与章节高亮保持方向感。

| 内容类型 | 适合使用的结构           |
| :------- | :----------------------- |
| 日常随笔 | 少量标题、引用和图片     |
| 操作指南 | 步骤、检查清单和提示框   |
| 技术笔记 | 代码块、表格和问题复盘   |
| 长篇文章 | 分层标题、目录和章节摘要 |

> [!TIP]
> 如果不知道从哪里开始，可以先写一个能独立成立的小段落，再围绕它补充背景、例子和结论。

想确认 spoiler 的交互效果，可以点击查看这段文字：:spoiler[它会在读者主动操作后显示，而不是一开始就占据全部注意力。]

> [!NOTE]
> 示例文章仅用于预览主题效果，不代表真实人物、网站或经历。

## 下一步

完成第一篇文章后，可以按下面的顺序继续整理站点：

1. 替换站点名称、头像、简介和社交链接。
2. 删除或改写这些示例文章。
3. 运行 `npm run check` 和 `npm run build`，确认内容与配置都能正常生成。
4. 在本地预览首页、文章列表、搜索、RSS 和文章详情页。

愿这里成为一处让文字慢慢沉淀的地方，也成为你愿意反复回来的地方。
